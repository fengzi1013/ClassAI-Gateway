# 机房内网AI助教网关
基于 FastAPI + DeepSeek API 搭建的局域网AI助教系统，专为学校机房场景设计。
学生端网页聊天，支持文本对话与图片识图提问；教师后台独立密码登录，实时查看全班学生使用情况，管控学生访问。

### ✨ 核心能力
**学生端（`http://教师IP:8000`）**
- 网页流式对话，支持文本+图片识图多模态提问
- 单IP每分钟请求限流，防止API超额消耗

**教师管理后台（`http://教师IP:8000/admin`，密码保护）**
- 实时监控全部学生内网IP，自动3秒刷新
- 查看：累计提问次数、最近提问预览、输入/输出/总Token消耗、全局Token汇总
- 管控功能：一键重置IP限流、拉黑/解除拉黑学生IP（远程切断访问）
- 一键导出全班统计CSV报表，Excel直接打开分析

### ⚠️ 重要提示
1. 所有统计、限流、黑名单数据**保存在内存**，网关重启后全部清空，适合单节课课堂使用。
2. 需要自行配置DeepSeek API密钥，部署在内网教师主机上。
3. 教师IP加入白名单，不受限流、拉黑限制。
4. 后台设置独立登录密码，学生无法进入监控页面。

### 快速启动
1. 安装依赖：`pip install fastapi uvicorn httpx`
2. 修改 `main.py` 配置：API密钥、内网白名单、后台管理员密码
3. 运行：`start_gateway.bat`
4. 学生访问：`http://教师IP:8000`；教师后台：`http://教师IP:8000/admin`

## 👨‍🏫 教师管理后台
访问地址：`http://教师IP:8000/admin`
- 实时查看所有学生IP的提问次数、最近提问内容、限流状态、Token消耗
- 页面自动3秒刷新，也支持手动刷新
- 密码保护，无密码无法查看学生使用记录
> 配置：修改main.py `ADMIN_PASSWORD` 设置后台登录密码
> ⚠️统计、限流、黑名单、token消耗全部保存在内存，网关重启，所有数据清空。

### 后台功能清单
✅ 查看每台学生机累计提问次数
✅ 查看最近提问的内容预览
✅ 实时查看是否触发限流
✅ 自动轮询刷新
✅ 一键重置单个IP的限流计数（学生被限流后，老师手动恢复）
✅ 拉黑/解除拉黑IP，远程切断学生访问（拉黑后该IP完全无法提交提问）
✅ 统计每个学生：输入Token、输出Token、总Token消耗，页面展示全局总Token
✅ 一键导出全班学生统计报表 CSV，可直接用Excel打开

> 保护规则：教师白名单IP**不能被拉黑**，也无需重置限流。

## 故障排查
|故障现象|根因|解决办法|
|---|---|---|
|访问 `/admin` 404|缺少admin.html文件，或者文件名字大小写不对|确认admin.html放在项目根目录，文件名小写|
|后台提示密码错误|main.py的ADMIN_PASSWORD和页面输入不一致|核对main.py里的后台密码|
|后台看不到学生记录|学生还没发送提问请求，统计是请求触发式；或者浏览器缓存|学生发送一条提问，教师后台刷新页面；清除浏览器缓存|
|点击拉黑按钮，提示不能拉黑|目标IP在WHITE_LIST教师白名单内|白名单是保护教师机，无法拉黑，属于正常逻辑|
|重置限流无效果|学生IP不在内存记录中，或者已经自然过期|让学生发一条提问，再执行重置操作|
|Token一直为0|DeepSeek流式接口的usage信息在流末尾返回；学生需要等回答完全输出后才会累计token|等AI回答完整返回，后台刷新页面即可看到token计数|
|导出CSV下载空白/乱码|Excel打开CSV中文乱码（Windows常见）|用记事本打开CSV，另存为UTF-8编码，再用Excel打开|
