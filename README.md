# 机房内网 AI 助教网关

基于 FastAPI + OpenAI 兼容协议大模型 API 搭建的局域网 AI 助教系统，面向学校机房教学场景。
学生网页端聊天，支持文本对话、图片识图提问；教师管理后台密码登录，实时监控全班学生使用情况，管控学生访问。

> 
> ⚠️重要提示
> 
> 
> 1. 统计、限流、黑名单、Session 会话全部存储在**内存**，服务重启后全部清空，适合单节课课堂使用；
> 2. 密钥、配置统一放在 `.env` 文件，**不要将 .env 文件分享或上传到代码仓库**；
> 3. 支持 DeepSeek、火山方舟豆包、通义千问、One‑API 中转等所有遵循 OpenAI 兼容流式协议的大模型；
> 4. 学生访问前端页面无需登录；教师后台受会话 Cookie 保护。

## ✨核心能力

### 学生端（`http://教师本机IP:8000`）

- 网页流式对话，Markdown 渲染回答；支持 Shift+Enter 换行，Enter 发送消息
- 支持文本提问、图片识图、上传文本类文件
- 单 IP 每分钟请求限流，防止 API 额度超额消耗
- 会话保存在浏览器本地内存，刷新页面对话丢失

### 教师管理后台（`http://教师本机IP:8000/admin`）

> 
> 使用独立管理员密码登录，登录后生成 HttpOnly 会话 Cookie，密码不再暴露 URL / 日志

- 实时监控全部学生内网 IP，页面默认 3 秒自动刷新，也可手动刷新
- 查看信息：累计提问次数、最近提问预览、输入 Token / 输出 Token / 总 Token 消耗、全局总 Token 汇总
- 管控功能：一键重置 IP 限流计数、拉黑 / 解除拉黑学生 IP（拉黑后该 IP 完全无法提交提问）
- 一键导出全班统计 CSV 报表，Excel 直接打开（内置 BOM 头，Windows 中文不乱码）
- 白名单教师 IP：不受限流、拉黑限制

## 快速启动

1. 安装依赖

```
pip install fastapi uvicorn httpx python‑dotenv
```

2. 在项目根目录新建 `.env`，复制下面配置，修改为自己实际参数

```
# ===================== LLM大模型接口配置（兼容OpenAI协议接口） =====================
# 大模型API Key  默认deepseek接口，其他可以不动，直接替换LLM_API_KEY="sk-xxx"即可
LLM_API_KEY="sk-xxx"

# 接口Base地址，例：https://api.deepseek.com/v1；火山方舟：https://ark.cn-beijing.volces.com/api/v1
LLM_API_BASE="https://api.deepseek.com/v1"
# 纯文本对话模型名称
MODEL_TEXT="deepseek-v4-pro"
# 支持图片识图的多模态模型名称
MODEL_VISION="deepseek-flash"

# ===================== 服务监听配置 =====================
# 服务监听地址 0.0.0.0 允许局域网其他机器访问；127.0.0.1仅本机访问
LISTEN_HOST="0.0.0.0"
# 服务端口号，学生浏览器访问地址 http://教师IP:8000
LISTEN_PORT=8000
# HTTP请求上游大模型接口超时时间，单位秒
TIMEOUT=120

# ===================== 学生访问限流管控 =====================
# 单IP每分钟最大提问次数
RATE_LIMIT_PER_MIN=6
# IP白名单，不受限流、拉黑限制；填写教师机内网IP，JSON字符串格式
WHITE_LIST='["127.0.0.1","6.163.159.195"]'

# ===================== 教师后台管理配置 =====================
# 教师管理后台登录密码
ADMIN_PASSWORD="admin123"
# Admin会话加密密钥，请自行替换为随机字符串，用于内存session签名，不要泄露
ADMIN_SECRET_KEY="f23ac71b901e42f885610cc22ee77a419f3528ab14c60123456789a"

# ===================== 请求安全防护配置 =====================
# HTTP请求体最大字节，防御超大base64图片payload；10485760 = 10MB
MAX_REQUEST_BODY_SIZE=10485760
# 学生单条用户文本最大字符数，超长直接拒绝请求
MAX_USER_TEXT_LENGTH=6000
```


3. 启动服务

- Windows：双击运行 `start_gateway.bat`
- 命令行：`python main.py`

4. 访问地址

- 学生聊天页面：`http://教师内网IP:8000`
- 教师管理后台：`http://教师内网IP:8000/admin`

> 
> 修改 `.env` 配置文件后，**必须重启网关服务才会生效**。

## 👨‍🏫教师后台使用说明

1. 访问 `/admin`，输入管理员密码点击登录；登录成功设置会话 Cookie，有效期 1 小时；服务重启需要重新登录。
2. 表格自动 3 秒轮询刷新学生数据，也可以点击【手动刷新】。
3. 操作按钮
   - **重置限流**：学生触发每分钟限流后，手动解除该 IP 的分钟计数。白名单 IP 不可重置。
   - **拉黑 IP / 解除拉黑**：拉黑后该 IP 完全无法调用 AI 提问。白名单教师 IP 禁止拉黑。
4. 【导出 CSV 报表】下载全班学生统计快照报表，Windows Excel 打开中文不乱码。

> 
> 注意：Token 统计依赖上游大模型流式返回的 usage 字段；部分国产大模型 SSE 流式不返回 usage，会出现 Token 一直为 0，属于上游接口限制。

## 安全特性（已完成优化）

1. 管理员后台不再 URL 携带密码，使用 POST 提交密码 + HttpOnly Cookie 会话登录，避免密码出现在访问日志、浏览器历史。
2. 请求体大小限制，拦截超大 base64 图片 payload，防止内存暴涨。
3. 单条用户文本字符上限，拦截超长输入。
4. 后台学生提问预览做 HTML 转义，防御 XSS 注入风险。
5. 全部密钥、配置从 `.env` 环境文件读取，不在源代码硬编码密钥。
6. CSV 输出 UTF‑8 BOM 头，Windows Excel 打开中文不乱码。

## 故障排查

表格

| 故障现象 | 根因 | 解决办法 |
| --- | --- | --- |
| 访问 `/admin` 返回 404 | 缺少 admin.html，文件名大小写错误 | 确认 admin.html 放在项目根目录，文件名小写 |
| 后台提示密码错误 | `.env`中`ADMIN_PASSWORD`和页面输入不一致 | 核对.env 配置，重启服务 |
| 后台看不到学生记录 | 统计为请求触发式；学生未发送提问；浏览器缓存 | 学生发送一条提问，刷新后台页面；清除浏览器缓存 |
| 点击拉黑提示不能拉黑 | 目标 IP 位于 WHITE_LIST 白名单 | 白名单用于保护教师机，禁止拉黑，属于正常逻辑 |
| 重置限流无效果 | IP 无内存记录，或者限流窗口自然过期 | 让学生发送一次提问，再执行重置操作 |
| Token 一直为 0 | 上游流式接口不在流中返回 usage；AI 回答未完整输出 | 等待 AI 完整输出回答；部分国产模型不支持流式 usage 统计 |
| 教师后台登录后刷新页面提示会话过期 | 服务重启，内存 Session 全部清空 | 重新登录后台 |
| 上传图片报错请求体过大 | 图片 base64 超出 MAX_REQUEST_BODY_SIZE 限制 | 调大.env 中 MAX_REQUEST_BODY_SIZE，同时 uvicorn 启动参数追加`--limit‑max‑request‑size=20971520` |

## 部署注意事项

1. 本项目设计用于**内网机房环境**，不建议直接暴露公网；如需公网部署需要额外增加安全加固。
2. 如果前端增加 Nginx 反向代理，需要处理真实客户端 IP 透传，否则限流、拉黑会全部识别为代理 IP。
3. 全部数据内存存储，重启丢失；如需持久化需要自行增加 sqlite 数据库。
4. 文件上传仅支持读取文本类文件；docx、pdf 二进制文件上传会读取乱码，不支持解析。
